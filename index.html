Autonomous self-navigating robot

Sep 2025 – Dec 2025 | Embedded systems

A robot that drives itself through a maze made of tape on the floor, running firmware I wrote in assembly for an HCS12 microcontroller.

The problem

The maze path is black tape on a white surface. The robot has to stay on the black, notice when it has drifted off, and recover when it runs into a wall, all in real time with no help from a computer.

How it works

Guider sensors on the underside of the robot read the surface beneath it. The firmware compares those readings against thresholds to decide whether the robot is on the path (black) or off it (white), and the control logic steers accordingly.

What I built

  • Firmware for the sensor-driven robot, written in assembly
  • Real-time control logic for detecting when it leaves the path
  • Collision adjustment for when it meets a wall

The hard part

Line tracking is only as good as its sensor readings. I debugged what the guider sensors were reporting and calibrated the threshold values, which improved tracking accuracy and kept the robot’s navigation stable.

Try it: line-following sim

A simplified simulation, not my actual firmware. The robot reads three noisy sensors under its nose and compares each reading to a threshold to decide “tape or floor.” It starts on the left and has to reach the finish line on the right. It rolls down the straight, overshoots the turns, bumps the walls, backs up and readjusts, then stops when it finishes. Press Reset to run it again, or drag the threshold to the extremes and watch it struggle.

Bookstore application

Jan 2025 – Apr 2025 | Desktop software

A JavaFX desktop app for running a bookstore, with separate experiences for the people who manage it and the people who shop in it.

The problem

A bookstore needs to track inventory and customers, handle purchases, and reward repeat buyers, while making sure each kind of user only sees and does what they should.

How it works

Role-based access separates administrators from customers. Administrators manage the stock, while customers register, make purchases and earn reward points.

What I built

  • Inventory management
  • Customer registration
  • Purchases and reward point tracking
  • A full-stack desktop app in Java and JavaFX

Design approach

I used object-oriented design and software design patterns to keep the code modular, so features could be added or changed without breaking the rest of the app.
